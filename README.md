# 📊 JGK MoneyHaven PRO — Chart Interaction Guide

This guide explains how to use the interactive chart features in the dashboard, including **zooming**, **panning (scrolling)**, and **resetting the view**.

---

## 🔍 Zoom In / Zoom Out

You can zoom into charts to analyze data in detail.

### 🖱️ Using Mouse Wheel

* Scroll **up** → Zoom **in**
* Scroll **down** → Zoom **out**

### 🤏 Using Touch (Mobile)

* Use **pinch gesture** (two fingers):

  * Pinch inward → Zoom out
  * Spread outward → Zoom in

---

## ↔️ Scroll / Pan (Move Left & Right)

Once zoomed in, you can move across the chart.

### 🖱️ Desktop

* Double Click and **drag left/right** on the chart

### 📱 Mobile

* Swipe left or right with one finger

👉 This helps you explore older or newer data points easily.

---

## 🔄 Reset Chart View

If you want to go back to the original full view:

* Click the **"Reset View"** button at the top of the dashboard

This will:

* Remove zoom
* Reset scroll position
* Show full dataset again

---

## 💡 Tips for Best Usage

* Zoom in to analyze **specific days or transactions**
* Use pan/scroll to navigate large datasets
* Reset view after deep zooming to avoid confusion

---

## ⚠️ Notes

* Zoom works only on the **X-axis (time/date)**
* Minimum zoom range is limited to avoid over-zooming
* Performance depends on data size

---

## 🚀 Summary

| Action     | Desktop      | Mobile     |
| ---------- | ------------ | ---------- |
| Zoom In    | Scroll Up    | Pinch Out  |
| Zoom Out   | Scroll Down  | Pinch In   |
| Scroll/Pan | Click + Drag | Swipe      |
| Reset View | Click Button | Tap Button |
